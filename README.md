# Ashmita Pariyar Portfolio

Static portfolio site for a Bench Sales Recruiter focused on US IT Staffing.

## Publish on GitHub Pages

1. Create a GitHub repository for this project.
2. Push these files to the repository.
3. In GitHub, open the repository settings.
4. Go to **Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose the `main` branch and the root folder `/`.
7. Save and wait for GitHub to generate the live URL.

## Share on Resume

Use one of these formats:

- Portfolio: `https://your-github-username.github.io/portfolio-repo/`
- Website: `https://your-github-username.github.io/portfolio-repo/`

## Search Visibility Tips

- Keep the site public.
- Use your full name and role in the title and hero section.
- Add the live link to LinkedIn, email signature, and resume.
- After publishing, submit the site URL to Google Search Console.

## Notes

- Replace the example GitHub Pages URL with the live URL GitHub gives you.
- If you later buy a custom domain, connect it in GitHub Pages settings.
